Which of the ten

A code (E1–E10), plus a weight and jank number off the controls. Reroll hand redraws every chair with a new random seed — same proportions, different wobble — so you can tell a bad chair from a bad roll.

Happy to mix: a stem angle from one and leg length from another is a two-number change.

How this ships

The generator runs once at build time, not in the browser — I bake the chosen chair’s path data into Chair.jsx as static SVG. No runtime cost, no per-render randomness.

That also means the exact chair you pick is the exact chair that ships, wobble and all.
